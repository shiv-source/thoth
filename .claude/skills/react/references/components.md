# Components (web/src)

The component index lives in **docs/frontend.md § Components** — the
authoritative table of every component under `web/src/components/`,
`web/src/shared/`, and `web/src/pages/` (path, purpose, props/api, canonical
file). Read it there, not here.

Conventions (hard-won facts not repeated in docs):
- One component per file; `*.test.tsx` co-located and skipped by convention.
- App shell (`app/App.tsx`, `main.tsx`, `theme.tsx`, `index.css`) is covered by
  docs/frontend.md § Structure, not the component table.
- antd v6 facts for writing new components: the react skill § The antd MCP.
